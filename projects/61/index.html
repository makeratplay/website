The Paulk Smart Bench

Multifunction table MFT and wood storage

Better Workbench

I purchased the plans for the Paulk Smart Bench and built it in my shop. I built the bench top exactly as the plans called for, but I modified the base to include a storage.

I purchased and used the UJK Parf Guide System Mark II to create and prefectly layout the 20mm holes in the bench top.
